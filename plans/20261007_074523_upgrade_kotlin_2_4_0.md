# Upgrade Kotlin to 2.4.0

**Status:** completed

## What the issue is

The Android build uses Kotlin (the Kotlin Gradle Plugin, KGP) **2.2.21**. Since the
Flutter 3.47.6 / AGP 9.4.1 upgrade (see
[change_log/20261007_073547_upgrade_flutter_agp_gradle.md](../change_log/20261007_073547_upgrade_flutter_agp_gradle.md)),
every Android build prints:

> Flutter support for your project's Kotlin version (2.2.21) will soon be dropped.
> Please upgrade your Kotlin version to a version of at least 2.3.20 soon.

Kotlin **2.4.0** is the version that new Flutter 3.47.6 projects use, and the newest
Kotlin that Flutter 3.47.6's tools know about. It is a published stable release.
(Newer 2.4.10 and 2.4.20 also exist, but 2.4.0 is what was requested and what Flutter
3.47.6 uses.)

The Kotlin version is set in one place only: `android/settings.gradle`. There is no
`ext.kotlin_version` or other Kotlin version anywhere else in the build files or docs.

## Files to be changed

- `android/settings.gradle` — `org.jetbrains.kotlin.android` plugin version
  2.2.21 → 2.4.0.
- `change_log/<timestamp>_upgrade_kotlin_2_4_0.md` — new change log.

Not changed: `android.builtInKotlin=false` stays as it is. Moving to Built-in Kotlin is a
separate, larger step (the plugins `dynamic_color`, `package_info_plus`, `pdfx`,
`share_plus`, `shared_preferences_android` must support it first).

## Plan for the fix

1. Change the version in `android/settings.gradle`.
2. Verify:
   - `flutter analyze` (must be clean),
   - `flutter test`,
   - `flutter build apk --flavor dev --debug` — check that the "Kotlin version ... will
     soon be dropped" warning is gone and the app's Kotlin code (`MainActivity`,
     `GhostScanActivity`, `GhostScanCaptureService`) still compiles,
   - `flutter build apk --flavor prod --release`.
   - Nothing is installed on a device.
3. If Kotlin 2.4.0 breaks the build (for example a plugin that does not work with it),
   stop and report instead of patching plugin code.
4. Write the change log and set this plan to `completed`.

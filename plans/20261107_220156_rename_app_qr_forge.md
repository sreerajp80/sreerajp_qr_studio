# Plan — Rename the app to "QR Forge"

**Status:** completed

## Issue

The app's display name is "SreerajP QR Studio". "QR Studio" is a generic name: many Play Store
apps use almost the same words, so the app is hard to find. The user chose a new name:

- Launcher / in-app display name: **QR Forge** (dev flavor: **QR Forge Dev**)
- Google Play store title: **QR Forge - Safe QR Scanner** (26 characters, limit 30)
- Malayalam: **ക്യുആർ ഫോർജ്**, Sanskrit: **क्यू-आर-फोर्ज्** (sounded out, matching how the
  existing "CodeForge" feature is written in Malayalam: കോഡ്ഫോർജ്)

The app is in closed testing (15 testers), so very few people know the old name.

## What does NOT change

- **Package id** `in.sreerajp.qr_studio` (and `.dev`). Changing it would make Google Play treat
  it as a new app. The Dart package name `sreerajp_qr_studio` also stays.
- **The "CodeForge" feature** keeps its name and its subtitle "Barcode & QR Studio" (user's
  choice). Note: users will see "QR Forge" on the launcher and "CodeForge" inside the app.
- Signing, keystore, version number (the next release bumps the version as usual).
- History: past entries in `CHANGELOG.md`, old `plans/`, old `change_log/`, and
  `docs/implementation_plan.md` (a historical document) keep the old name.
- `play_store_private/SUBMISSION_RECORD.md` (a record of past submissions).
- `test/screens/about_screen_test.dart` uses a made-up "Test QR Studio" name; it is test
  data, not the app name.
- `docs/guidelines/` (read-only submodule).

### Store listing (gitignored folder, local only)

## Steps

1. Make the edits above.
2. Run `flutter gen-l10n`, `dart format .`, `flutter analyze`, `flutter test`.
3. Grep again for "QR Studio" and confirm only the allowed leftovers remain (history files,
   CodeForge subtitle, test data, package ids).
4. Write the change log.

## What the user does afterwards (not part of this change)

- Build and install the dev flavor to see the new launcher name (user runs it).
- In Play Console, change the store title and paste the updated description. Google reviews
  listing changes again.
- Update the hosted copy of the privacy policy if it is published somewhere.

## Native-reader review

- Malayalam ക്യുആർ ഫോർജ് and Sanskrit क्यू-आर-फोर्ज् are sound-outs of an English brand
  name. "फोर्ज्" is an English loanword, which is normal for a brand name, but flag both for
  a native reader in the change log.

## Security impact

Touches Android resource files (`android/` platform folder) for the app name only. No change to
permissions, manifest settings, storage, network, signing or dependencies. No security impact.

# Remove the Custom Text / Device Sync toggle from the AirQR transmitter

**Status:** completed

## The issue

The AirQR transmitter screen has a toggle at the top with two tabs: **Custom Text** and
**Device Sync**.

- **Custom Text** sends text the user types.
- **Device Sync** sends this app's own scan history and settings to another phone,
  locked with a PIN.

These are two different jobs. A user who opens "AirQR transmitter" from the scanner menu
expects to send their own text. Seeing a "Device Sync" tab there is confusing: it is not
clear what it syncs.

Device Sync already has its own entry points:

- Settings → **AirQR Optical Sync** card (opens the transmitter with `syncMode: true`).
- History export/import dialog → **Beam via AirQR** button (same).

So the toggle is not needed to reach Device Sync.

## The fix

Make the screen show one job only, chosen by how it was opened. No toggle.

1. **Opened from the AirQR menu** (no `syncMode`): Custom Text only. Title stays
   "AirQR transmitter".
2. **Opened from Settings or Export/Import** (`syncMode: true`): Device Sync only. The
   app bar title is "AirQR Optical Sync" (existing key `titleAirQrSyncSettings`, already
   translated in `en`, `ml`, `sa`).

Details in `lib/screens/air_qr_transmitter_screen.dart`:

- Delete the `SegmentedButton` and its `onSelectionChanged` handler.
- Keep the `AirQrTransmitMode` enum and `_mode` field. The mode is now set once, from
  `startInSyncMode` or the `syncMode` route argument, and never changes while the screen is
  open.
- App bar title: `_mode == AirQrTransmitMode.deviceSync ? l10n.titleAirQrSyncSettings :
  l10n.titleAirQrTransmitter`.
- No change to the frame building, PIN, encryption or broadcast code.

Localization:

- The keys `labelAirQrModeText` and `labelAirQrModeSync` are used only by the toggle.
  Remove them (and the `@` entries) from `app_en.arb`, `app_ml.arb`, `app_sa.arb`, then run
  `flutter gen-l10n`.
- No new strings are needed.

The receiver side (`air_qr_screen.dart`) does not change. It already detects a sync package
by itself.

## Files to change

- `lib/screens/air_qr_transmitter_screen.dart` — remove the toggle; title depends on mode.
- `lib/l10n/app_en.arb`, `lib/l10n/app_ml.arb`, `lib/l10n/app_sa.arb` — remove the two
  unused toggle keys.
- `lib/l10n/gen/*` — regenerated by `flutter gen-l10n`.
- `test/screens/air_qr_transmitter_screen_test.dart` — add tests:

    text field shown.
  - `startInSyncMode: true` (every declared language): title is `titleAirQrSyncSettings`,
    passphrase field shown, no text payload field, no toggle.

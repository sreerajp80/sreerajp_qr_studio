# Plan — One home for app graphics: `docs/graphics/`

**Status:** completed

## The issue

App graphics live in two places today, and the two sets do not match:

- `docs/screenshots/` (committed, about 6.9 MB, 10 files). The README uses them. They are old:
  they show the old app name ("Sreeraj P QR Reader" / "SreerajP QR Reader") and version 3.1.2.
- `play_store_private/graphics/` and `play_store_private/screenshots/` (gitignored, local only).
  These are the current Play Store images: the 512 × 512 icon, the 1024 × 500 feature graphic
  ("QR Forge"), and 6 captioned phone screenshots (1080 × 1920).

So GitHub shows old pictures, the Play images are not backed up in git, and every update has
to be done twice.

## The fix

Make `docs/graphics/` the single home for every picture that GitHub or Google Play shows.
Private text (data safety answers, publishing guide, submission record, the foreground
service video) stays in `play_store_private/`.

New layout:

```
docs/graphics/
  app_icon_512.png                 # Play icon
  feature_graphic_1024x500.png     # Play feature graphic (also a README banner)
  screenshots/
    01_link_check.png              # the 6 captioned Play screenshots,
    02_payment_check.png           # in Play upload order
    03_scanner.png
    04_codeforge.png
    05_wifi.png
    06_airqr.png
```

Steps:

1. Move (not copy) the 2 graphics and 6 screenshots from `play_store_private/` into
   `docs/graphics/`, with `git mv`-style moves so there is one copy only.
2. Leave `play_store_private/screenshots/raw/` where it is. The raw captures are work files for
   re-making the captioned images; they are not shown anywhere, so they do not need to be
   public or in git.
3. Delete the old `docs/screenshots/` folder (10 files). They show the old name and version.
   Git history keeps them if ever needed.
4. `README.md`: replace the "Visual Showcase" 3 × 3 table with the feature graphic as a banner
   and the 6 new screenshots (two rows of three), with short captions.
5. `docs/project_structure.md`: add `docs/graphics/` to the folder tree and the table.
6. `docs/release_process.md`: in the store readiness checklist, say store graphics live in
   `docs/graphics/` (and that the private folder holds only text answers and the video).
7. Local only (gitignored, not committed): update the paths in
   `play_store_private/store_listing.md` and `play_store_private/PUBLISHING_GUIDE.md` to point at
   `docs/graphics/`.

## Files to change

## Privacy check (done before the plan)

All 8 images were looked at. They show only made-up example data
(`paypal-login.example.com`, `shop@example`, "Example Cafe" / `demo-password`, `https://example.com`).
No real UPI ID, payee, phone status bar or personal data. They are safe to make public.

## Security impact

None. Only images and docs move. The private folder stays gitignored.

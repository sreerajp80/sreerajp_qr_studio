# Toolchain upgrade: Flutter 3.50.1, Kotlin 2.4.20 (AGP 9.4.1, Gradle 9.8.0 confirmed)

**Status:** completed

## What the issue is

The request is to move the build toolchain to Flutter 3.50.1, AGP 9.4.1, Gradle 9.8.0 and
Kotlin 2.4.20. A check of the project shows:

| Tool    | Now in project | Target  | Work needed |
| ------- | -------------- | ------- | ----------- |
| Flutter | 3.47.6 (Dart 3.13.5) pinned in docs, CI and `pubspec.yaml` | 3.50.1 (Dart 3.14.0) | Yes. The SDK on the machine is already 3.50.1; only the pins change. |
| AGP     | 9.4.1 (`android/settings.gradle`) | 9.4.1 | None |
| Gradle  | 9.8.0 (`gradle-wrapper.properties`) | 9.8.0 | None |
| Kotlin  | 2.4.0 (`android/settings.gradle`) | 2.4.20 | Yes |

## Files to change

1. `android/settings.gradle` — Kotlin plugin `2.4.0` → `2.4.20`.
2. `pubspec.yaml` — `environment`: `sdk: '>=3.14.0 <4.0.0'`, `flutter: '>=3.50.1'`.
3. `pubspec.lock` — regenerated by `flutter pub get` (not edited by hand).
4. `.github/workflows/ci.yml` — `flutter-version: '3.50.1'`.
5. `CLAUDE.md` and `AGENTS.md` — identity table: Flutter 3.50.1, Dart 3.14.0 (kept in step).
6. `README.md` — badges and the two version lists: Flutter `>=3.50.1`, Dart `>=3.14.0`.
7. `docs/architecture.md` — toolchain line: Flutter 3.50.1 / Dart 3.14.0.
8. `CHANGELOG.md` — one line under `[Unreleased]`: toolchain moved to Flutter 3.50.1 and
   Kotlin 2.4.20.

Not touched: `docs/guidelines/` (read-only submodule), `native/zxing-cpp/`, the global
Gradle memory settings.

Note: `CLAUDE.md`, `AGENTS.md` and some docs already have uncommitted edits from earlier work.
This plan only changes the version lines in them.

## Plan for the fix

1. Make the edits listed above.
2. Run `flutter pub get` (updates `pubspec.lock`).
3. Checks, given to the user to run (learning-first rule):
   - `flutter analyze` — must stay at zero issues. Dart 3.14 may add new lints.
   - `flutter test`
   - `flutter build apk --flavor dev --debug` — proves Gradle, AGP and Kotlin 2.4.20 work
     together, including the native zxing-cpp build.
   - Then `android\gradlew --stop` and check no `GradleDaemon` / `KotlinCompileDaemon` is left.
4. Fix any new analyzer warnings or build errors that the upgrade causes (if a fix is more
   than small, come back with a plan update first).
5. Write the change log in `change_log/`.

## Raising the `pubspec.yaml` lower bound — trade-off

Raising `flutter: '>=3.50.1'` means anyone on an older SDK can no longer build. That is the
point (the project is tested on 3.50.1, and CI pins it), and it matches how the bound was set
before. If you prefer, we can leave the `pubspec.yaml` bounds alone and only change the pins.

## Security impact

Build toolchain only. No change to permissions, network, storage or dependencies' code.
Kotlin 2.4.20 is a patch release from JetBrains via the Gradle plugin portal (same source
as today). Low risk.

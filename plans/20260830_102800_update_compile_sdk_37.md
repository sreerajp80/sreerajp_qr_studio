# Plan: Update Android compileSdk to 37

**Status:** Approved

## Issue
Running the release APK build command `flutter build apk --flavor prod --release --split-per-abi` produces a build warning and requires Android SDK version 37 or higher because the `receive_sharing_intent` plugin compiles against Android SDK 37:
```text
Warning: The plugin receive_sharing_intent requires Android SDK version 37 or higher.
Your project is configured to compile against Android SDK 36, but the following plugin(s) require to be compiled against a higher Android SDK version:
- receive_sharing_intent compiles against Android SDK 37
```

## Solution
1. In `android/app/build.gradle`, update `compileSdk` from `flutter.compileSdkVersion` to `37`.
2. In `android/build.gradle`, update the fallback `compileSdkVersion` in the subprojects block from `36` to `37`.

## Files to Change
- `android/app/build.gradle`: Set `compileSdk = 37` in the `android` configuration block.
- `android/build.gradle`: Set `compileSdkVersion 37` in the subprojects fallback block.

## Verification
- Run `flutter analyze` to ensure Dart static analysis remains clean.
- Run `flutter test` to ensure all tests pass.
- Run `flutter build apk --flavor prod --release --split-per-abi` to verify that the APK builds cleanly without the SDK version mismatch warning.

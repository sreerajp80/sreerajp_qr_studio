# Plan — Fix the StegoQR and AirQR lines in the store description, and the Safe Browsing text on the Privacy screen

**Status:** completed

## The issue

While making new store screenshots on 26 October 2026, three wrong claims were found.

1. **StegoQR (store description).** Under CREATE CODES the description says:
   "StegoQR: hide a secret message inside a normal-looking QR code, locked with a passphrase."
   The app can only **open** StegoQR codes. It cannot make them. The app's own Help says
   "This app can open these codes, but it does not make them" (`helpGuideHiddenSafetyBullet3`).
2. **AirQR "files" (store description).** The description says "AirQR sends files, scan
   history and settings". The AirQR transmitter has only two modes: **Custom Text** and
   **Device Sync** (history and settings). There is no file option.
3. **Safe Browsing text (in the app).** On Settings → Privacy, with Active online checks off,
   the English text (`bodyPrivacyExplainerOff`) says: "Malicious-content lookup **still uses**
   Google Safe Browsing". The code (`lib/services/url_safety_service.dart`,
   `checkGoogleSafeBrowsing`) skips Safe Browsing unless the user has saved their own API key.
   So the English text wrongly suggests every link goes to Google.
   The Malayalam and Sanskrit texts are wrong the other way: they say links are **never** sent
   to any outside server, which is not true when the user has turned on a safety service.
   They are also not translations of the English text.

**Checked and correct (no change):** the store description line "Online checks (Google Safe
Browsing and others) are optional and off until you turn them on", `PRIVACY_POLICY.md` §4
("Only for the providers you turn on in Settings. All are off by default."), and
`play_store_private/data_safety_answers.md` (the link may be sent to safety services; declared
as optional). These all match the code.

## The fix

### 1. Store description (`store_listing.md` §3)

- **CREATE CODES:** remove the StegoQR line. Keep "Make your own QR codes and barcodes with
  colours, styles and a logo." (CodeForge has a centre logo option.)
- **SCAN ANYTHING:** add:
  `• Opens locked codes, such as StegoQR codes with a hidden message: type the passphrase to see it, right on your phone.`
- **SHARE WITHOUT INTERNET:** change to:
  `• AirQR sends text, scan history and settings from one phone to another using animated QR codes. No Wi-Fi, Bluetooth or cables needed.`
- Re-count the length (limit 4000) and update the "Updated" line.

### 2. Privacy screen text (`bodyPrivacyExplainerOff`)

- **en:** "SSL, redirect and shortener checks use local rules only, so the scanned site is
  never contacted. A link is sent to a safety service, such as Google Safe Browsing, only if
  you turned that service on in Settings."
- **ml:** "SSL, റീഡയറക്ട്, ഷോർട്ട്‌നർ പരിശോധനകൾ പ്രാദേശിക നിയമങ്ങൾ മാത്രം ഉപയോഗിക്കുന്നു; സ്കാൻ ചെയ്ത സൈറ്റുമായി ബന്ധപ്പെടുന്നില്ല. ക്രമീകരണങ്ങളിൽ നിങ്ങൾ ഓണാക്കിയ സുരക്ഷാ സേവനത്തിലേക്ക് (ഉദാ. Google Safe Browsing) മാത്രമേ ലിങ്ക് അയയ്ക്കൂ."
- **sa:** "SSL-पुनर्निर्देशन-लघुकरण-परीक्षाः अन्तस्थनियमैः एव भवन्ति; संवीक्षितं जालस्थानं न सम्पर्क्यते। भवता विन्यासेषु सक्रियीकृतायै सुरक्षासेवायै (यथा Google Safe Browsing) एव जालबन्धः प्रेष्यते।"
- `@bodyPrivacyExplainerOff` description: say it must stay true to the code (local checks
  only; safety services only when the user turned them on).
- Run `flutter gen-l10n`.
- Ask native readers to check the ml and sa lines (listed in the change log).

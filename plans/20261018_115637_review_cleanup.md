## Issues found

1. **QuishingGuard still sits under a "computer vision" heading.** On the
   Features screen it is in the "Vision tools" group, whose subtitle
   (`descFeaturesCatVision`) says "Cutting-edge on-device computer vision…".
   After the last change QuishingGuard no longer looks at the picture, so this
   heading quietly brings back the old claim. It fits better in the "Safety"
   group.
2. **Unused text keys.** These keys are in all three ARB files but no code uses
   them:
   - `labelPercentValue` — was only used by the removed risk bar.
   - `tooltipCameraAdjustments`, `tooltipZoomControls`, `tooltipResetStream` —
     not used before this work either (the buttons use other tooltip keys).
3. **Old wording left for translators and in a comment.**
   - `@titleFeatureQuishingGuard` description: "QuishingGuard tamper detection
     feature".
   - `@bodyOnboardingSlide2` description: "explaining sticker tampering" (fine
     in meaning, but update to "fake sticker check" to match).
   - `lib/l10n/app_message_text.dart`: an empty `// printed-code tamper check`
     section comment with no cases under it.
4. **Small edge case in the scanner screen.** In `didChangeDependencies`, when
   the `CameraSettingsProvider` instance changes, the old one is told the
   camera is off, but the new one is not told the camera is on. In practice the
   provider never changes, but the fix is one line and keeps the light sensor
   state correct if it ever does.

# Change log: Upgrade Kotlin to 2.4.0

Implements plan: [plans/20261007_074523_upgrade_kotlin_2_4_0.md](../plans/20261007_074523_upgrade_kotlin_2_4_0.md)

## What changed

- `android/settings.gradle` — `org.jetbrains.kotlin.android` plugin version changed
  from 2.2.21 to 2.4.0. This is the only place the project sets a Kotlin version.

`android.builtInKotlin=false` was not changed.

## Why

Since the Flutter 3.47.6 / AGP 9.4.1 upgrade, every Android build warned that Flutter
support for Kotlin 2.2.21 will soon be dropped (minimum asked: 2.3.20). Kotlin 2.4.0 is
the version new Flutter 3.47.6 projects use, and the newest Kotlin its tools know about.

## Verification

- `flutter build apk --flavor dev --debug` — built. The "Kotlin version ... will soon be
  dropped" warning no longer appears. The app's own Kotlin code compiled.
- `flutter build apk --flavor prod --release` — built.
- `flutter analyze` — no issues.
- `flutter test` — all 472 tests passed.
- Nothing was installed on a device.

## Still open (not part of this change)

Flutter still warns that the app and these plugins apply the Kotlin Gradle Plugin and
should move to AGP "Built-in Kotlin": `dynamic_color`, `package_info_plus`, `pdfx`,
`share_plus`, `shared_preferences_android`. Future Flutter versions will fail to build
until this is done.

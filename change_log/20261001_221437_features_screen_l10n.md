# Change log: Features screen text moved into ARB files (en / ml / sa)

Implements plan: [plans/20261001_220849_features_screen_l10n.md](../plans/20261001_220849_features_screen_l10n.md)

## What was wrong

`lib/screens/features_screen.dart` had all feature text hard-coded in English
inside a `static const` list. Malayalam and Sanskrit users saw English on this
screen. This broke the rule that all user-visible text comes from
`lib/l10n/*.arb`.

## What changed

### `lib/l10n/app_en.arb`, `app_ml.arb`, `app_sa.arb`

- Added 140 new keys right after `featuresHeaderSubtitle`, in all three files:
  - 10 category keys: `featuresCat<Name>Name`, `featuresCat<Name>Subtitle`
    (`Scanning`, `Safety`, `Vision`, `Payloads`, `History`).
  - 130 feature keys: `feature<Name>Title`, `feature<Name>Desc`,
    `feature<Name>Chip1`–`Chip3` for 26 features.
- Every English key has an `@key` description.
- English text is the same as the old literals.
- Malayalam and Sanskrit follow the terms the app already uses (for example
  `ബാർകോഡ്` / `दण्डलेखा` for barcode, `ഗോസ്റ്റ്സ്കാൻ` / `छायावीक्षणम्` for
  GhostScan, `अनुप्रयोगः` for app in Sanskrit). Format names
  and standards (QR, PDF417, HTTPS, UPI, TOTP, vCard, CSV, JSON) stay in Latin
  script.
- Every chip label is 22 characters or less in all three languages (checked by
  script).
- Sanskrit text was checked against the Hindi-marker gate before running the
  tests. Two words that contained a forbidden substring (`सङ्ग्रहेण`,
  `ग्रहीतुं`) were replaced with `सञ्चयेन` and `ज्ञातुं`.

### `lib/screens/features_screen.dart`

- Replaced `static const List<_FeatureCategory> _categories` with
  `static List<_FeatureCategory> _buildCategories(AppLocalizations l10n)`.
- `build()` now calls `_buildCategories(l10n)` and loops over the result.
- Icons, order and layout are unchanged. The file has no user-visible string
  literals left.

### `lib/l10n/gen/*`

- Regenerated with `flutter gen-l10n`.

## Checks

- `flutter gen-l10n` — ok.
- `dart format .` — 0 files changed.
- `flutter analyze` — no issues found.
- `flutter test` — all 472 tests passed, including the ARB parity tests, the
  Sanskrit Hindi-marker gate, and `settings_screen_test.dart` (which still finds
  the title 'SreerajP QR Reader Features' from `featuresHeaderTitle`).

# Change log: Gaps 10–12 (Sanskrit history crash, AR mode switch, AirQR camera blocked)

## Result

- `flutter analyze`: no issues.
- `flutter test`: all 571 tests pass. The Sanskrit History test that failed
  before now passes; no failing test is left.

## Gap 10 — History screen no longer crashes in Sanskrit

- New `lib/l10n/date_format_locale.dart`: `dateFormatLocale(localeName)`
  returns the locale when `intl` has date data for it, else `'en'`.
- `lib/screens/widgets/history_card.dart` uses it for both date and time.
  The words around the date stay in Sanskrit; only the date numbers and
  month name use English format.
- Tests: new `test/l10n/date_format_locale_test.dart` (3 cases); the
  Sanskrit case in `test/screens/history_screen_test.dart` now passes.

## Gap 11 — AR CodeVision mode switch

- `lib/screens/ar_codevision_screen.dart`: a Warehouse / Safety
  `SegmentedButton` under the app bar title, with icons and tooltips. It is
  shown in every state.
- `lib/providers/ar_codevision_provider.dart`: changing mode clears the
  selection (selection and Batch Copy exist only in Warehouse mode). The mode
  is not saved; the screen still opens in Warehouse mode.
- New ARB keys (English, Malayalam, Sanskrit): `arModeWarehouse`,
  `arModeSafety`, `arModeWarehouseTooltip`, `arModeSafetyTooltip`.
- Tests: 2 new provider cases; 4 new screen cases (switch in all three
  languages, tapping changes the mode).

## Gap 12 — AirQR receiver handles a blocked camera

- `lib/screens/air_qr_screen.dart`:
  - Asks for camera permission when the screen opens (point of use), like the
    Scanner and AR screens. The camera controller is created only after
    permission is granted.
  - Permission denied: camera icon, "Camera permission required", and a
    "Grant permission" button that asks again (existing keys).
  - Camera error: "Camera could not start" or "No camera found on this
    phone", with a "Try again" button that restarts the camera. A permission
    error from the camera plugin shows the permission message.
  - "Initializing…" (`airQrInitializing`) is now shown only while the camera
    is starting, instead of forever after an error.
- New ARB keys: `cameraStartFailed`, `cameraNotFound`, `cameraRetryButton`.
- Tests: `test/helpers/test_app.dart` — the camera platform fake is now
  `fakeCameraPlatform({bool granted})`. `test/screens/air_qr_screen_test.dart`
  covers the denied state in all three languages, asking again, and the
  "could not start" / "Try again" state (real-time wait for the camera
  plugin answer, using `tester.runAsync`).

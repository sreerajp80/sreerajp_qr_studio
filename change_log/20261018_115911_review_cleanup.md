# Change log: full app review cleanups

Implements plan: `plans/20261018_115637_review_cleanup.md`

## Summary

A full review of the app found it in good shape (analyze clean, format clean,
all tests pass, localization and security checks pass). This change fixes the
four small leftovers the review found.

## What changed

1. **QuishingGuard moved to the Safety group** — `lib/screens/features_screen.dart`.
   It was under "Vision tools", whose subtitle talks about "on-device computer
   vision". QuishingGuard no longer looks at the camera picture, so it now sits
   at the end of the Safety group. Its title, text and chips are unchanged.
2. **Removed 4 unused text keys** from `lib/l10n/app_en.arb`, `app_ml.arb` and
   `app_sa.arb`, and regenerated `lib/l10n/gen/*` with `flutter gen-l10n`:
   - `labelPercentValue` (only the removed risk bar used it)
   - `tooltipCameraAdjustments`, `tooltipZoomControls`, `tooltipResetStream`
     (never used)
3. **Old wording cleaned up**
   - `app_en.arb`: the translator notes for `titleFeatureQuishingGuard` and
     `bodyOnboardingSlide2` now say "fake sticker check" instead of "tamper".
   - `lib/l10n/app_message_text.dart`: removed an empty
     `// printed-code tamper check` section comment.
4. **Light sensor state on provider swap** — `lib/screens/scanner_screen.dart`.
   When the camera settings provider changes in `didChangeDependencies`, the
   new provider is now told the camera is on if it is running. Before, only the
   old provider was told it was off.

## Not done

- The plan said to add a test that QuishingGuard is in the Safety group, if the
  features test could see groups. The test only checks texts on the screen and
  has no way to tell which group a tile is in, so a group check would be
  fragile. It was skipped.
